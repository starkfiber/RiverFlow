02

A real guest, a bounded claim.

The RF2 VMM creates a VM, maps separate code and data pages, sets CPU registers, handles exits and releases resources. Its three-instruction ARM64 guest adds two inputs, writes the sum and exits.

  • 40 local guest runs, including permission and mapping faults
  • Read-only guest data remains unchanged on refused writes
  • VM resources are reacquired after cleanup in the same process

Apple supplies hardware virtualization. This is a VMM foundation, not a Linux boot, virtual device model or transistor redesign.

03

Compatibility is a feature check.

A browser with WebAssembly uses the compiled module. Without it, this page offers an ES5-compatible sum implementation. That fallback covers this example, not every RF2 program.

No physical Android 4.1 browser has been tested. OS version alone does not identify the browser's WebAssembly support. Older browser TLS and installation limits remain separate.
