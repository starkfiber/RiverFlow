# Ten practical intelligence layers for the RF2 ship

These are project-specific engineering directions, not claims of universal novelty.
Implemented candidates are distinguished from remaining proposals.

| # | Layer and benefit | Current status / code | Decisive next gate |
|---|---|---|---|
|1|Verified recipe context: use exact legal syntax and callable capabilities instead of asking models to guess RF2|Built: `report/context.py`, manifest-bound card + admitted `style.flow`|Freeze a new same-model authoring study with/without the exact card; compare complete successes, retries and reported usage|
|2|Typed report composition: one domain result serves JSON/HTML clients without duplicated formatting|Built: `report/report.flow`, complete `file-summary.flow`|Add typed nested/optional data only with explicit ownership and invalid-state contracts; do not invent a generic JSON AST now|
|3|Shape-aware serialization: ordinary spans and exact scalar fallback reduce repeated checks|Built: `sdk/json_spans.flow`, source package route|Broader real caller workloads, including aliasing and mixed densities, must beat baseline without hiding tiny-case losses|
|4|Protocol-phase specialization: separate fixed header/options/trailing padding without removing rejection|Built: Net checked tail scan; actual unchanged state oracle|Guest adapter trial and durable lease/reservation integration under the Net owner branch|
|5|Bounded arithmetic kernels: replace serial authentication work with independently checked limb operations|Built: Ship AEAD candidate + actual PC/Q35 guest checks|Full acceptance suite, exact target assembly review, threat-model-based erasure/side-channel review before promotion|
|6|Compiler-feedback repair contracts: hand the model stable diagnostic categories and a tiny correct syntax recipe|Executed one successful DeepSeek repair; provider/compile/37-case receipts local|Implement bounded reviewed repair admission and multi-attempt stop rules; same model/context controls; never execute unsolicited provider commands|
|7|Dependency-aware context graph: retrieve only referenced nominal types, effects and API contracts|Proposed extension of prior inventory/context tooling, not implemented semantic graph|Compiler-produced edges must match adversarial forward-call/import/ownership fixtures; incomplete edges must not authorize a patch|
|8|Workload-guided build selection: use measured clean/cache cost, not a universal cache flag|Prior sprint's advisory selector exists; no new speed claim here|Integrate exact compiler/source/options-keyed observations into developer loop; include first build, edit and clean-correctness controls|
|9|Replayable state-transition capsules: carry minimal packet, generation, clock and expected output through Net/Ship regressions|Existing guest/oracle cases executed; portable capsule/causal minimizer remains proposed|Minimized replay must reproduce original failure without changing oracle, secret material or nonce/state contract|
|10|Target qualification registry: compiler/ABI/HAL/model/runtime evidence determines which code can run where|Partial source/manifest/native context checks only; full registry proposed|Mac, x86 guest and ESP32 records remain distinct; missing backend/physical proof returns unknown rather than promising universal execution|

Paths1–6are under `experiments/evolution-20261117/`. The priority is useful complete
programs and measured authoring reliability, retaining typed values/persistence and
the broader RF2 Everywhere mission. Adding proposed layers to a table is not their
implementation or a release gate passed.
