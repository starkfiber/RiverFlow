02 / A LANGUAGE WITH A FOUNDATION

Simple at the start.
Explicit underneath.

The ambition is one coherent creation system across applications, devices and operating systems. Each capability earns its place through implementation and tests.

01

Native work, without a runtime shopping list.

The RF2 compiler is written in RiverFlow. The qualified Mac toolchain emits ARM64 programs. Native user tools run without Node, npm, Python or a C++ runtime installation.

Apple Silicon Mac
02

Build on a capability. Keep the details inspectable.

Shared libraries carry familiar work such as input handling, checked arithmetic and timer lifecycles. Focus and Stretch are six-line native app configurations over a tested shared library.

See the app evidence ↗
03

A target is a real contract.

Mac applications and the ESP32-C3 emulator work are distinct targets. Drivers, firmware, operating systems and new hardware need their own acceptance evidence.

Target by target

03 / HUMANS AND AI, WITH CLEAR RULES

AI beside you.
Rules you can inspect.

An AI host can help write a program and use RF2’s bounded MCP tools. The host supplies the intelligence. RF2 makes supported operations and their limits explicit.

Understand the tool boundary ↗
