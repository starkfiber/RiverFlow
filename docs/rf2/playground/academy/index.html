NAME THE IDEA

A name. A value.
A useful memory.

let creates the name; set changes its value. ask receives an answer; show displays a result. You can inspect the values beside the code rather than guessing what happened.

Variable
A name for a value the program remembers.
Condition
A check that chooses which instructions run.

A small group of instructions repeated under a rule.
