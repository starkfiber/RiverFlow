# RF2 Learning Studio

Three beginner missions use actual Simple V3 source: remembered values, a group-fit
condition, and a three-pass loop. The existing bounded RF2 browser worker compiles,
steps and executes these programs. JavaScript renders the interface, stars, door,
source editor, controls and record download. This does not replace the browser,
create a native widget toolkit or implement WebAssembly execution.

Choose Next step to execute one actual instruction. Watch code run repeats that
operation at a visible pace. Pause stops automatic steps; a waiting input does not
run until answered. Still pictures and the reduced-motion preference disable
transitions without replacing computation. The picture caps stars at12; full
numeric values remain visible. A lesson goal comes from the program's `solved`
variable; editing the source changes that exercise, not a protected academic grade.

The source editor stages drafts. Apply code & restart checks the draft and starts
an execution. Restart uses the last checked source, explicitly offering to discard
an unapplied draft. A failed Apply does not replace the last checked program.
Restore this lesson reloads the actual original source, including after a failed
source download. Loading, compile, runtime and input errors have visible states.

Execution-record downloads capture a source-bound snapshot, supplied answers,
trace and unsigned SHA-256 identity. The record is not authentication, academic
approval or a native speed benchmark. Failed worker replies bind the attempted
source and error; transport errors without a worker reply have no false record.

Visual principles follow the requested Start UI reference: reusable learning
surfaces, responsive layouts, restrained transitions and tested interactions.
No Start UI code, React dependency or third-party artwork is copied or installed.
Brand remains SFE and the site stays buildless.
