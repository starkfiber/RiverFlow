Keep a simple syntax guide beside you
Say, remember, change
say "Hello!"
let points = 2
set points = points + 3
show points
Quotes hold text. A name remembers a value. show calculates a whole number.
Choose or repeat
if points >= 5
 say "You did it!"
else
 say "Try again."
end
repeat 3 times
 say "Go!"
end
end closes a block. Conditions use zero for false and a nonzero number for true.
Ask and reuse
fn twice(n)
 return n * 2
end
ask number age "Your age?"
show twice(age)
ask number reads a whole number. ask name "Your name?" reads text. A function here returns one numeric calculation.
Simple V3 uses checked unsigned 64-bit whole numbers: no negative numbers or decimals yet. / requires an exact whole result; // rounds down; ** means power. Programs have explicit source, work and output limits. This learning subset does not expose files, networks or machine permissions.

    UNDERSTAND THE ENGINE
    Fast is something
    we measure.
    A shorter program can be easier to write. Runtime speed also depends on the algorithm, data and target. This playground makes those distinctions visible.
    Browser mode compiles the supported Simple V3 subset into reference bytecode and runs it in a bounded worker. Native local mode uses the real Mac ARM64 toolchain. Dynamic Simple programs currently include a native engine. Neither mode proves universal C or assembly superiority. General OS, device and GUI programming are separate development tracks.
