This same .flow program accepts direction numbers in the console and drives the board here. Change let turns = 6 to let turns = 8, apply, then try again.

The forward/backward helpers use a comparison as 1 for true and 0 for false, so a move adds or subtracts only while there is room. The reusable FlowSession binding sends answers to RF2 and reads its values. HTML and CSS provide this graphical interface. A general RF2-only native widget toolkit is not implemented by this page.
