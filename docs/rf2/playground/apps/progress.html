Developer boundaries that remain
  • The native CLI helpers use raw, correctly sized, disjoint buffers and shared non-reentrant scratch. They are not a general memory-safety layer.
  • The generated SDK caller ignored output statuses and exited successfully with stdout closed. That retained probe lies outside the 43 content/refusal cases. Numeric JSON is exact text; ordinary JavaScript consumers can round large u64 values.
  • The reusable GUI components are browser bindings around RF2 rules. They do not constitute a native widget toolkit or automatic app generator.
  • RF2 does not train a model by running these tests. People and AI hosts change source, verify behavior and retain project records. Human learner trials remain open.
