THE SAME WIDGETS, ANOTHER PROGRAM

A points counter.
No new form plumbing.

This separate RF2 program reuses the exact same input, actions, source editor, receipt and state-session components. Add a few whole-number points. The counter logic remains in its own .flow file.

What is shared?

InputForm, Metric, Status, Actions, SourcePanel, ReceiptPanel and RuleView are imported from one UI module. The existing FlowSession connects both apps to the actual bounded RF2 worker. A small app-specific projection validates the values used by each view; it does not decide when to turn heating on or add points.

These interfaces are HTML, CSS and JavaScript around RF2 rules. This is a reusable browser binding, not a native RF2 widget toolkit, an automatic GUI builder or a measured development-token advantage.
