Your starting point

The local Simple V3 learning kit is for Apple Silicon macOS. It includes the selected native frontend, compiler, help, examples and existing bounded Core tools. It has passed a fresh-extraction qualification outside the source checkout.

Download the local learning kit ↓

Extract RF2-Learn-V3-macos-arm64.zip. Open Terminal in the extracted RF2-Learn-V3-macos-arm64 folder. Start with:

./rf2 learn
./rf2 academy/examples/simple/hello.flow
./rf2 examples/guessing-game.flow

Native user execution needs no Node, npm, Python or C++ runtime installation. macOS provides the shell, signing and system utilities. Save your own .flow files in this folder to use the short ./rf2 command.

This is a local learning candidate, ad-hoc signed rather than notarized. The kit does not change security settings or quarantine attributes. Its README, file manifest and download checksum identify what was supplied.

Already using the full RiverFlow checkout? The same short commands work there with its selected qualified artifacts. ./rf2 status shows the tool selection. A fresh source clone may not include unpublished binaries. Published downloads elsewhere may support an older profile; read current status before mixing editions.

01. Say something

In a plain-text editor, save this as hello.flow:

say "Hello, world!"

Run it from the RiverFlow folder:

./rf2 hello.flow

You should see Hello, world!. Change the message to your name and run it again. say adds a new line for you. Text inside quotes can include Tamil and other valid UTF-8 text.

Save this hello.flow example ↓

02. Give a value a name

let points = 2
set points = points + 3
show points

let remembers a value under a name. set changes it. show calculates and displays a number. This program prints 5.

Try changing 3 to 8. Predict the answer before running it. If you type a different name by mistake, RF2 explains that the name has not been introduced.

Save this points.flow example ↓

03. Ask a question

ask number age "How old are you?"
show age + 1

Save as age.flow, then run ./rf2 age.flow. Enter 12 and press Enter. After the question, it prints 13.

ask remembers text. ask number asks for a whole number that calculations can use. The terminal may echo what you type; that echo is separate from the program’s output.

This beginner profile currently uses nonnegative whole numbers, rather than fractions or negative answers. / must divide exactly; // gives the whole-number quotient; % gives the remainder; ** means a power.

Save this age.flow example ↓

04. Keep a native program

./rf2 build age.flow age
./age

The saved executable needs no compiler installation to run on the qualified Mac. An existing output path is protected. Constant-only programs keep a small specialized output path; variable/input programs currently include the native Simple engine.

The whole program’s grammar, names and types are checked before a question appears. Answers can still cause a later error, such as division by zero. Earlier prompts can remain visible; an unfinished result is not printed as success.

AI beside you

An AI host can help write and review RF2. The executable does not contain an embedded model. You can inspect an input plan locally:

./rf2 inspect age.flow

That command shows potential questions, expected text/number kinds and program effects without asking for answers. A loop can ask a listed question more than once, and a branch can skip it; the plan is not a fixed questionnaire. It is a CLI inspection command, separate from the existing nine bounded Core MCP tools.

Core tools accept their declared bounded computation profiles. They do not run arbitrary Simple input or trusted Systems source. Interactive input needs a separately defined tool contract; it must not be mixed into the JSON-RPC stream.

05. Choose a path

Locally tested Simple V3 candidate. These examples require the selected local development toolchain. They are not supported by the earlier published Core 0.17 profile.

let points = 12
if points >= 10
 say "Level up!"
else
 say "Keep practising."
end

if chooses a path. else supplies the other path. end closes the block. Numeric zero is false and a nonzero number is true. Comparisons == != < <= > >= return zero or one. Compare two values at a time rather than writing a chain.

Introduce a variable before a block; change it inside the block with set. A question inside a block updates an existing name of the same kind. The whole source is checked, including a branch that is not taken.

06. Repeat a useful step

repeat 3 times
 say "Keep building."
end

The repeat count is evaluated once. The candidate accepts up to 1,000 repeats, with a shared 4,096 work budget that can stop expensive programs earlier.

let remaining = 3
while remaining > 0
 show remaining
 set remaining = remaining - 1
end

while tests the condition again each time. The update is what makes this countdown finish. An endless or overly expensive loop is refused by the work budget. This is a bounded Simple execution rule, not an operating-system sandbox for arbitrary full-native code.

07. Give a calculation a name

fn twice(n)
 return n * 2
end
show twice(3)

A function names a reusable calculation. This prints 6. Current Simple functions are deliberately small: one numeric return expression, up to four numeric parameters, and at most eight functions. They can call other functions without a recursive cycle.

A function uses its own inputs rather than outside variables. It does not ask questions or perform IO. These are current Simple rules; the full native language has a broader, separately documented contract.

Read a whole small program

These exact candidate sources are downloadable without an account. The frozen local candidate passed its acceptance checks. Downloading source is not browser execution; use the qualified local tools.

  • Guess the Number ↓: three attempts, high/low hints and a fixed secret of 7. It does not claim randomness.
  • Double Quiz ↓: three rounds, a numeric function and a score. It is not an adaptive AI tutor.
  • Work Planner ↓: whole-number job/worker counts with a zero-worker path. It is a count planner, not a measured scheduler.

After selecting the qualified V3 tools, run ./rf2 guessing-game.flow. To keep a native executable, use ./rf2 build guessing-game.flow guessing-game. This command creates an ordinary executable file; it does not package a macOS .app bundle.

Keep growing

Full native RF2 adds explicit functions, modules, resource rules and platform contracts. The Simple V3 conditions, loops and numeric functions described above are locally tested. Their exact tests and release boundary remain separate from broader platform claims.

The broader destination includes applications, devices and operating systems. Reaching each target needs real compiler, runtime, driver and application evidence.
