## Mission that must survive a chat change

One coherent, readable language and SDK for humans and AI, from a child's first program to useful applications, devices and eventually system software/RU’OS. Preserve `.flow`, existing working backends and reproducible evidence. The aim is competitive leadership through useful complete jobs, measured against mature languages and stacks. Broader targets, graphics, games, SDKs and AI integration remain in scope as destinations.

“Everywhere” requires a real backend, ABI, runtime/service adapter, libraries, UI/device integration, packaging and acceptance execution per target. Names, equations, syntax and prior papers do not implement those components. AI intelligence comes from a host unless a separately tested model is integrated. No promise that every hardware-specific program runs unchanged everywhere.

## Anti-drift rules

1. Choose work from the pipeline and state the acceptance condition. Fix reproduced failures before widening claims.
2. Current priority: typed application values and ownership, then typed persistence and a real Booking integration. Do not substitute another invoice demonstration for these foundations.
3. Keep compiler correctness, runtime speed, rebuild speed, energy, model usage and learner usability as separate measurements. Keep losses and equally specialized baselines. Leadership is an objective, not current evidence.
4. Default/optimized behavior, cleanup, refusals, ABI and MCP boundaries matter. Trusted Systems source never silently acquires bounded Core/MCP admission.
5. Keep stable packages, development bundles and isolated experiments distinct. Finite generated cases are not thousands of human developers, real learners or independent reviewers.
6. Publish SFE upstream writes only through a verified actual `starkfiber` account. Preserve the terminal push lock and identity backups. No alternate-account fallback.
7. SFE/Moontek/Stark continuity stays in project-owned local files. Never send it to Kanika Memory or retained shared compute. No unrelated infrastructure operations.
8. No thesis or PDF work in this software track unless the owner changes that scope. Preserve private research files and existing public paths.
