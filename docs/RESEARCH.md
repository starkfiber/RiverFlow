# Research foundation and next experiments

Creator: Ilangkhumanan Thirunavokkarasu. These are research directions, not publisher endorsements or established novelty.

The prior private research library contains 13 projects. No thesis text, recovered third-party source, participant data, device calibration or private operational evidence is bundled here. Names below identify proposed links, not implemented integrations.

| Research direction | Useful RF² question | Current boundary |
|---|---|---|
| Kernel 8 | Can deterministic work and effects be specified clearly? | Core work limits are not scheduling guarantees. |
| Kernel 9 | Can adaptive proposals be admitted through deterministic checks? | No adaptive planner in this release. |

| Marketing, HR and organisational studies | What makes language tooling understandable and adoptable? | User research remains prospective. |
| ZeniOS | Can immutable profiles support evolvable systems? | Profile versioning only, no OS isolation claim. |

First experiment: independently compare bounded programs against simple native implementations at equal semantics. Record correctness, compilation cost, warm execution, tail latency, memory, code size and full failures. Do not import M5 gains as phone gains.

Next: define a single service extension and two backends. One uses an established OS API; the second can target a native experiment. Compare complete success/error/cancel/restart traces. A hosted success does not prove native hardware replacement. A firmware ACK does not prove network connectivity.

Transistor reinvention is a separate physical-design research programme requiring device models, simulation, fabrication and measurement. The language can eventually describe experiments; this implementation does not establish new semiconductor technology.
