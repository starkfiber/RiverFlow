# Separate complete-program output-contract pilot

The matched C/D study-1 is finished and preserved: 0/4 complete tasks. This pilot
is a different experiment, not a replacement arm or another matched comparison.
Repeated literal-placeholder output motivates the change but does not prove its
cause. Prior costs, length failures and unknown usage remain in that study.

Only change the system and task output instructions from literal JSON placeholder
examples to a prose contract requiring one JSON object whose single source value
contains the actual complete RF2 program beginning with its profile declaration.
Task C/CLI semantics, common guide, staged SDK, qualified compiler, independent
oracle, model deepseek-v4-pro/thinking-low, 10,000 completion cap,180-second HTTP
and195-second transport budgets stay the same. Freeze actual initial payload,
controller/protocol and prior closed study identities before any new call.

One initial proposal, at most one repair only after actual reviewed-source
assessment failure. Maximum two calls, no retries after length, missing source,
transport or parsing failure. An incomplete response consumes its round. Every
source proposal requires coordinator full effect review and exact SHA approval
before assessment. Contract/import errors reject without native execution. A
valid proposal builds as the same optimized native program and faces all86 Task C
oracle cases including exact bytes, invalid inputs and output failures. Use the
guarded local bank only for reproducible binaries; preserve source and evidence.

Report complete pass/failure, all known usage including failures, unknown usage
explicitly, request/build/test time, and source/compiler/SDK identities. Reasoning
and cache counts are subsets of total provider usage, not additional tokens or
billing. No causal prompt diagnosis, general productivity percentage, manual/CLI
comparison, hardware speed, field qualification or stable release claim follows.
No project material goes to Memory/KHC/Chain; transport holds credentials remotely
and sends only the reviewed synthetic programming payload to the provider.
