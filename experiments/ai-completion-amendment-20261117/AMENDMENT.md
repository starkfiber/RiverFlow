source (only trailing LF changed), retaining duplicate local names and unsupported
syntax. The existing repair prompt appended source/feedback without an explicit
repair action. This amendment adds an explicit instruction to fix actual failures,
repeats already supplied language rules, and quotes numbered source context only
around compiler-reported source locations. It supplies no task solution or golden.

Original frozen inputs and prior attempt files remain unchanged; new rounds append to the existing campaign directory. A separate
root-reviewed amendment receipt pins this wrapper and document plus the original
freeze. It operates on the SAME sequential arm/round ledger with the SAME12-call,
2-repair, reported180000-token, timeout and source-review limits. It cannot issue
an initial round. No successor campaign, unlimited retries or oracle relaxation.
Repeated source is explicitly recorded as a failure, never rewritten. This is a
mid-campaign engineering change; amended/unamended attempts must be distinguished
in before/after reporting. Every original model failure/token cost stays included.
No stable/live changes, Memory/KHC work, or credential material in evidence.
