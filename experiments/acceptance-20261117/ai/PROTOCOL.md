# Cost to independently passing software, frozen before inference

Two complete native tasks, Line metrics and Match metrics; fixed order A/manual,
A/report, B/report, B/manual. Same qualified compiler, SDK source bytes, current
language/API guide, native-admitted common syntax example, model and reasoning
settings. The report condition alone adds the typed Report API and permits that
import; manual condition composes exact bytes through Writer primitives. Both
receive the same task and independent acceptance oracle. No solution source is
included in either prompt. Gold reference apps are controller validation only.

Model: deepseek-v4-pro, thinking enabled/low, max5000completion tokens per call,
120second HTTP/135second transport observation. At most one repair per attempt,
eight calls total. No automatic retry for transport, length or policy failures.
Repairs see actual compiler/functional feedback. Each proposed source is manually
reviewed and hash-confirmed before native execution. Do not execute model commands.
Only synthetic selected files and bounded local processes are used.

Freeze source/task/style/guide/grader/SDK/compiler identities before the first call.
Exclusive attempt/round directories retain failures and actual served model/usage,
cache/reasoning counts and elapsed generation/build/test time. Existing study is
not rerun or amended to a win. This is a small new two-task engineering comparison,
not evidence across general languages, developers or hardware.

Primary: number of independently correct tasks within two calls. For each success
count ALL its initial+repair input/output/reasoning tokens and time to success.
Also report total condition spend including failed attempts, and spend per passing
task (undefined if none). Never count a failed short output as a saving. Report
output correctness, protocol refusal and I/O faults independently of source size.
Token counts are provider-reported usage, not measured billing or dollar savings.
The actual card/recipe trial differs from the earlier four-failure experiment;
do not pool or erase its outcomes. No release/tag/binary update follows from this
study. Project-owned retention only; no Memory/Chain/shared harness sessions.
