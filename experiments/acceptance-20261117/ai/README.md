# Useful AI development, not answer compression

The implemented library `text-report-cli.flow` centralizes exact argument and mode
validation, bounded regular-file loading, UTF-8/C0 checks, typed JSON/HTML report
composition, checked writes and refusal propagation. Applications implement one
synchronous typed callback for actual calculations. `CLI-API.md` specifies the
trusted Systems boundary; this is not an arbitrary-effects sandbox.

`reference-cli-A.flow` and `reference-cli-B.flow` exercise line metrics and
case-sensitive overlapping byte search respectively. Both pass the unchanged
46/160 complete-task controls in plain and optimized native modes. These are
handwritten admission controls, not model productivity evidence.

Two initial model programs and their one allowed repair each failed compilation.
Two other condition attempts failed in transport with unknown usage; the original
5,000-completion-token budget also yielded reasoning without complete source.
All failures and their costs remain in local receipts. No token saving is claimed
from source size, compressed context or a partially correct answer.

The separately predeclared `cli-supplement/` study uses the new library in two fresh
calls with no retries or repair. Both generated applications compile and pass the
unchanged complete-task oracle on their first call (46/46 and 160/160). Independent
exact-mode/query-boundary and
callback-error controls supplement that oracle. It is a new,
nonrandomized engineering condition, not a matched causal productivity result.
Provider credentials are read only by the explicitly authorized transport host;
source proposals are never executed until independently reviewed by exact hash.
No model commands are run. Unique study artifacts stay project-local, not in a
shared Memory/Chain/compute job or disposable cache. Native images alone use the
local guarded disposable cache.

Frozen studies are intentionally immutable. Follow-up protocol changes get new
controllers/directories and preserve old failures. The two new calls report 6,887
and 7,241 tokens (14,128 total), 45.601/54.964 seconds respectively. The amended
manual A/B initial+repair attempts used 33,099 known tokens and still failed;
the earlier capped call used 7,274 without complete source.
Two transport attempts have unknown usage. This does not establish a general
causal savings percentage. Read the final acceptance summary for boundary and
combined-package results; complete-task success, not brevity, is the outcome.
