# Measured RF2 evolution candidate

Source and exact oracles for three native optimizations and shared report/context
composition. [Results, failures and scope](../../docs/MEASURED-EVOLUTION-20261117.md).
The stable runtime, downloaded releases and active external Net/Ship checkout
are not replaced by this experiment.

- `sdk/`: ordinary-byte JSON spans, scalar alias/density fallback, exact state
  comparisons, document serialization and distribution benchmarks.
- `net/`: complete copied DHCP baseline/candidate, independent state/byte oracle,
  padding controls, deliberately wrong native mutant and source-bound PATCH.diff.
- `ship/`: complete bounded AEAD baseline/candidate, CryptoKit/exact-integer/
  sanitizer oracles and isolated x86 guest adaptation. PATCH.diff targets the
  original active branch only when its exact recorded source still matches.
- `report/`: complete typed JSON/HTML report and native-checked authoring context,
  independently graded application, bounded provider experiment with failures.
- `package.py NEW-DIRECTORY`: combined explicitly selected source SDK. Existing
  SDK and compiler interfaces remain intact; no package download or live effect.

Native comparisons require the exact qualified0.50 Mac compiler recorded in the
receipts. Developer controllers use Python/Clang/Swift/QEMU as documented; the
compiled RF2 report application has no Python or Node runtime dependency.
RF2Ship's existing bounded Clang-encoded crypto port is not a general RF2 x86
compiler backend. Test totals overlap and are not a unique population or proof.

Tests run locally because native Darwin execution and excluded project retention
boundaries prevent the shared KHC route. No Kanika Memory, Chain, retained company
compute session or live networking is involved. No cryptographic/side-channel
certification, universal hardware coverage or AI-token saving is claimed.
